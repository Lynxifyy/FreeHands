What's inside

Built to keep going after the first draft

Most agents stop when the code compiles. FreeHands keeps reading, running and fixing until the repository is actually in the state you asked for.

◎

Oli, not a rebrand

Oli knows its own name, its own limits and its own standards. Ask who it is and it answers honestly. Ask for a Luau script and it writes one.

⌘

Free model router

Router Pro and Router Flash pick a model per task. They work out of the box, and you can point them at your own provider whenever you want.

⚡

Mini windows

Keep a second conversation open in a small, draggable, read-only window while you work in the main one. It remembers where you left it.

✓

Static tester

Before Oli hands work back, it critiques every file it touched and fixes what won't compile, won't connect or isn't finished.

⌁

Real statuses

Thinking, reading, editing, running, searching, waiting. The status comes from real events, so it never says "working" while nothing is happening.

⧉

Multiple repositories

Attach more than one repository to a conversation. The selection persists and reaches the agent instead of disappearing on reload.

Modes

Three ways to work, one agent

Code mode is the default. Plan mode writes the plan before touching a file. Complex Code mode runs on OpenCode for large, multi-file changes.

Code

Implement, run and verify directly. The default for everyday work.

Plan

Produce an ordered plan and stop before editing anything.

Complex Code

Built for changes that cross many files. Reads the whole path, follows imports and callers, and keeps going until the project's own checks pass.

Automations

Work that runs without you

Six new automations ship in this release, alongside the existing catalog. Each one runs in your repository and reports what it changed.

Repository health sweep

Install, lint, type-check, test and build — then fix what is provably safe.

Static correctness audit

Dead imports, unreachable branches, mismatched types and broken build paths.

Test gap finder

Finds behaviour no test exercises and writes the highest-value missing tests.

Dependency and CVE guard

Upgrades safe dependencies and lists anything with a breaking change.

PR shepherd

Reproduces failing checks, pushes the smallest fix and reruns until green.

Release notes writer

Turns commits into grouped notes with breaking changes first.

Install

One container, three services

The image bundles the agent server, the automation service and the frontend behind a single port. Your conversations and settings live in ~/.openhands.

shell 
docker run -d --name freehands \
  -p 8000:8000 \
  -e AGENT_CANVAS_ALLOW_LAN_SESSION_KEY=true \
  -e FREEHANDS_MAX_ACTIVE_CHATS=3 \
  -v "$HOME/.openhands:/home/openhands/.openhands" \
  -v "$HOME/projects:/projects" \
  ghcr.io/lynxifyy/freehands-agent-canvas:1.33.0

Then open http://localhost:8000/canvas/. Set AGENT_CANVAS_ALLOW_LAN_SESSION_KEY=true only when the port is reachable by you alone.
